# To-Do Reminder App

Це мобільний додаток-нагадувач, розроблений за допомогою React Native та Expo, який дозволяє користувачам додавати, переглядати, та видаляти завдання з можливістю отримання push-сповіщень через OneSignal.

## 🔧 Вимоги

Перш ніж почати, переконайтеся, що у вас встановлено:

- **Node.js** (рекомендується LTS версія)
- **npm** або **Yarn**
- **Expo CLI**: `npm install -g expo-cli` або `yarn global add expo-cli`
- Емулятор Android / iOS або фізичний пристрій з встановленим додатком Expo Go.

## Встановлення

1.  **Клонуйте репозиторій** (якщо ви використовуєте Git) або завантажте файли проекту.
2.  Перейдіть до кореневої папки проекту:
    ```bash
    cd your-project-folder
    ```
3.  Встановіть залежності проекту:
    ```bash
    npm install
    # або
    yarn install
    ```

## Конфігурація OneSignal

Цей проект використовує OneSignal для push-сповіщень. Вам потрібно буде створити обліковий запис OneSignal та налаштувати додаток:

1.  **Зареєструйтесь на [OneSignal](https://onesignal.com/)**
2.  **Налаштуйте платформу Android** Вам знадобиться `APP ID` та `REST API Key`.
3.  **Оновіть `app.json`**: Додайте `extra` секцію з вашими ключами OneSignal.
    ```json
    // app.json
    {
      "expo": {
        "extra": {
          "oneSignalAppId": "YOUR_ONESIGNAL_APP_ID", // Замініть на ваш App ID
          "oneSignalApiKey": "YOUR_ONESIGNAL_REST_API_KEY" // Замініть на ваш REST API Key
        }
      }
    }
    ```
4.  **Встановіть залежності OneSignal**:
    ```bash
    expo install react-native-onesignal
    ```

## Запуск проекту

Щоб запустити проект на вашому пристрої або емуляторі Android:

1.  Переконайтеся, що ваш емулятор Android запущений, або ваш фізичний пристрій підключений та дозволяє налагодження по USB.
2.  У кореневій папці проекту виконайте команду:
    ```bash
    npx expo run:android
    ```
    Ця команда збере пакет додатку та запустить його на підключеному пристрої або емуляторі.
