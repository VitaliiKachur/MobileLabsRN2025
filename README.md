# 📁 LAB-5: Мобільний файловий менеджер

Цей проєкт — це мобільний файловий менеджер, створений за допомогою **React Native** та **Expo**. Він дозволяє користувачам керувати файлами на пристрої: створювати, редагувати, переглядати, видаляти файли й папки, а також переглядати інформацію про об'єкти файлової системи та статистику памʼяті.

---

## 🚀 Швидкий старт

### 1. Клонування репозиторію

```bash
git clone <repository-url>
cd LAB-5
```

### 2. Встановлення залежностей

```bash
npm install
# або
yarn install
```

### 3. Запуск проєкту

```bash
npm start
# або
yarn start
# або
expo start
```

---

## 📱 Запуск на пристрої

1. Встановіть **Expo Go** 
2. Відскануйте QR-код, що зʼявиться у терміналі або браузері

### Емулятор/Симулятор

- Android: натисніть `a` в терміналі
- iOS: натисніть `i` в терміналі

---

## 🏗️ Структура проєкту

```
LAB-5/
├── .expo/                  # Конфігурація Expo
├── assets/                 # Ресурси (іконки, зображення)
├── node_modules/           # Зовнішні залежності
├── src/                    # Вихідний код
│   ├── components/         # Повторно використовувані компоненти
│   │   ├── FileItem.js         # Елемент списку файлів
│   │   └── InputModal.js       # Модальне вікно вводу
│   ├── screens/            # Екрани додатку
│   │   ├── HomeScreen.js
│   │   ├── FileManagerScreen.js
│   │   ├── FileViewerScreen.js
│   │   ├── FileEditorScreen.js
│   │   ├── FileInfoScreen.js
│   └── utils/
│       └── fileSystem.js       # Робота з файловою системою
├── App.js                  # Головний файл додатку
├── app.json                # Expo конфігурація
├── package.json            # Скрипти та залежності
└── README.md               # Цей файл
```

---

## 🔧 Встановлення додаткових залежностей

```bash
npx expo install expo-file-system

npx expo install react-native-screens react-native-safe-area-context
```
